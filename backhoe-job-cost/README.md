# คิดต้นทุนงานดิน — แอปคำนวณต้นทุน–กำไร งานขุดดินถมดิน / รถแบ็คโฮ

แอปมือถือ (PWA) สำหรับผู้รับเหมางานขุด–ถมดินที่มีรถของตัวเอง สร้างตาม design handoff
"Backhoe Job Cost" (design system **Organic** — ครีม–ดินเผา–เขียวเสจ)

## ทำอะไรได้

- **งาน** — เห็นทุกงานที่ทำอยู่ พร้อมยอด รับ / ทุนรวม / เหลือ‑ขาดทุน และแถบเตือนเมื่อกำไรต่ำกว่าเป้า
- **บันทึกรายวัน** — เที่ยวสิบล้อ ชั่วโมงแบ็คโฮ คนงาน น้ำมัน เงินที่เจ้าที่จ่าย ฯลฯ
  แอปเติม**ค่าแรงให้อัตโนมัติ**จากอัตราที่ตั้งไว้ (คนคุมงาน / คนขับสิบล้อรายเที่ยว /
  คนขับแบ็คโฮวันหรือชั่วโมง / ช่างซ่อม / ค่ากินคนงาน)
- **พูดใส่แอป** — พูดหรือพิมพ์ประโยคเดียว เช่น
  `"10 ล้อมาส่ง ขี้แร่ 10 เที่ยว ลงหน้างานลุงยาว คนงาน 4 คน"`
  แอปแยกเป็นช่อง ๆ ให้ยืนยันก่อนบันทึกทุกครั้ง (แก้ได้ทุกช่อง มีฟอร์มปกติเป็น fallback)
- **เงิน** — เหลือทั้งเดือน กราฟ 6 เดือน ค่ารถ/ค่าแรงแยกก้อน เงินค้างรับ (เตือนเลยกำหนด)
  งานที่ต้องระวัง และส่งออก Excel/CSV รายเดือน
- **รถ-คน** — สรุปต่อรถแต่ละคัน (hour meter + เตือนถ่ายน้ำมันเครื่อง), อัตราค่าแรง
  (สลับหน่วยได้), ตัวคูณหน่วยวัสดุ คิว ↔ ตัน ↔ เที่ยว, ตัวเทียบราคาเหมาเที่ยว vs รายชั่วโมง
- **Offline-first** — ข้อมูลเก็บในเครื่อง ใช้ได้ไม่มีเน็ต แล้วซิงก์ขึ้นหลังบ้านเมื่อออนไลน์

## กติกาคำนวณ (ตาม handoff §6)

- ต้นทุน = **ค่ารถ + ค่าแรง** แสดงแยกสองก้อนทุกที่
- **ห้ามนับซ้ำ**: รถร่วมที่ติดธง "รวมคนขับ" จะไม่ถูกคิดค่าแรงคนขับซ้ำ และขึ้น label เขียวเสจ
- เหลือ = รายรับ − (ค่ารถ + ค่าแรง) · ต่ำกว่าเป้า (default 20%) ขึ้นแถบเตือนดินเผา
- หน่วยวัสดุ: เก็บดิบเป็นเที่ยว แล้วแปลง `คิว = เที่ยว × คิว/เที่ยว`, `ตัน = คิว × ตัน/คิว`
- กำไรใช้เขียวเสจ ขาดทุนใช้ดินเผาเข้ม (ไม่ใช้แดง–เขียวสด)

ข้อมูลตัวอย่างในแอปตรงกับ acceptance test ใน handoff:
งาน "ถมที่ลุงยาว" 50 เที่ยว × 900 = รับ 45,000 · ค่ารถ 42,400 · ค่าแรง 12,500
→ ทุน 54,900 → **ขาดทุน 9,900** · ค้างรับ 15,000
(ล้างข้อมูลตัวอย่างได้ที่ หน้าเงิน > ฟันเฟือง > "ล้างข้อมูลตัวอย่าง")

## วิธีใช้งาน

### แบบเครื่องเดียว (ง่ายสุด)
เปิด `index.html` ผ่านเว็บ (เช่น GitHub Pages:
`https://<user>.github.io/rescue-banbueng/backhoe-job-cost/`)
แล้วกด "เพิ่มไปยังหน้าจอโฮม" — ใช้ได้เลย ข้อมูลเก็บในเครื่อง

### แบบหลายเครื่อง (มีหลังบ้าน)
1. สร้าง Google Sheet ใหม่ > Extensions > Apps Script > วางโค้ดจาก `Code.gs`
2. แก้ `TEAM_CODE` และ `PIN` ในโค้ด แล้วรัน `setup()` หนึ่งครั้ง
3. Deploy > New deployment > **Web app** > Execute as: Me / Access: **Anyone**
4. คัดลอก URL `/exec` ไปวางในแอป: หน้า **เงิน** > ปุ่มฟันเฟือง > API URL + รหัสทีม + PIN
5. ทำแบบเดียวกันทุกเครื่อง — ข้อมูลจะซิงก์หากันอัตโนมัติ (last-write-wins ต่อรายการ)

## หมายเหตุ

- ปุ่มพูดใช้ Web Speech API (`th-TH`) — ใช้ได้ดีบน Chrome/Android; ถ้าเครื่องไม่รองรับ
  แอปจะให้พิมพ์แทนโดยอัตโนมัติ
- ตัวเลขค่าแรง/ราคาในข้อมูลตัวอย่างเป็นตัวเลขสมมติจาก handoff — ตั้งของจริงได้ในหน้า รถ-คน
- ยังไม่รวม: แนบรูปหน้างาน, ใบเสนอราคา PDF, สิทธิ์ผู้ใช้หลายระดับ (owner/คนขับ) —
  โครงข้อมูลรองรับไว้แล้ว เพิ่มได้ภายหลัง
